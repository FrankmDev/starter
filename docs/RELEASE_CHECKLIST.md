# Release checklist for derived projects

- [ ] Project configuration uses real verified branding, domain, locale and metadata.
- [ ] bun ci, bun run verify and bun run audit pass.
- [ ] Mobile, desktop, keyboard navigation and browser console are reviewed.
- [ ] Images have meaningful alt text, stable dimensions and appropriate LCP priority.
- [ ] Canonicals, robots, sitemap and structured data represent the real published site.
- [ ] Staging, demo and placeholder pages are not indexed.
- [ ] Actual integrations have appropriate CSP, privacy, consent and secret handling.
- [ ] Interactive states, errors, forms and external links work.
- [ ] No invented business claims, policies, ratings, addresses or unfinished content.
- [ ] Final deployed result is verified and a rollback path is known.
